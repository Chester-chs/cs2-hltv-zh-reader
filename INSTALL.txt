CS2 HLTV 中文阅读器 1.0.3 — 安装说明

一、解压
1. 下载 ZIP 后，右键选择“全部解压”。
2. 解压后的文件夹中必须直接看到 manifest.json、background.js、content.js、popup.html 和 options.html。
3. 不要在浏览器中选择 ZIP 文件；如果文件夹里还有一层同名文件夹，请进入能直接看到 manifest.json 的那一层。

二、Chrome
1. 地址栏打开 chrome://extensions。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择包含 manifest.json 的文件夹。
5. 扩展出现后，点击工具栏拼图图标并固定它。

三、Edge
1. 地址栏打开 edge://extensions。
2. 打开“开发人员模式”。
3. 点击“加载解压缩”，选择包含 manifest.json 的文件夹。

四、配置翻译服务
1. 打开 HLTV 页面，点击扩展图标，再点“服务商与首次设置”。
2. 选择 DeepSeek、OpenAI 或自定义服务商，填写模型名和自己的 API Key。
3. 点击“授权”，允许访问你填写的服务商域名。
4. 点击“保存”，再点击“测试连接”，看到“连接成功”后刷新 HLTV 页面。
5. 页面翻译可选“完全中文”或“双语对照”。选中单词会出现放大镜，点击后可查词；选中句子可翻译整句。

五、更新
1. 下载新版 ZIP 并先解压到临时文件夹。
2. 将新版文件夹内的全部文件复制到浏览器正在加载的原安装文件夹，替换同名文件。保持原安装路径；移除扩展或更换路径可能丢失设置、历史和收藏。
3. 在扩展管理页点击“重新加载”，确认版本为 1.0.3，再刷新已经打开的 HLTV 标签页。

本版新增：词典卡片的牛津官方词典/等级词表核对入口；等级标记为模型参考，发音标记为系统语音。改进释义分号拆分、未核实原形处理、多标签页记录保存、查词等待时保留输入、已打开卡片的主题和外观同步。牛津官方数据和录音尚未接入。

本次修正：复习答案点击后显示、复习按钮防重复和保存错误提示、复习时禁用清空/筛选、导出保留仅在收藏中的词条、外观字段分别保存、系统发音口音选择与失败提示。复习从开始时的收藏列表建立一轮固定顺序，退出或重启后旧请求不会跳过新一轮的词条。

六、常见问题
- 出现 background.scripts requires manifest version 2：删除旧扩展实例，确认加载的是新版文件夹；新版只使用 Manifest V3 service_worker。
- 页面没有更新：在扩展管理页点击“重新加载”，然后强制刷新 HLTV 标签页。
- 新闻仍是英文：检查 API Key、服务商域名授权和“测试连接”结果。
